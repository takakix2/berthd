# assets

The berthd mark: a pier with a bollard, and a mooring line looped around it. The pier is one colour, the line and its ring another (a blue gradient, so it sits beside its sibling tools).

| File | Use |
|---|---|
| `berthd-logo.svg` | 256×256, rounded dark background. App / site icon. |
| `berthd-mark.svg` | The mark alone, transparent. For dark backgrounds (pier is off-white). |
| `berthd-mark-light.svg` | The mark alone, transparent. For light backgrounds (pier is dark grey). |
| `berthd-windows-terminal.png` | Windows Terminal 3-pane split screenshot (1115×628). Promo / Reddit. |

The ring passes around the bollard: the far half is drawn behind the post, the near half cuts a gap into it (a mask, so it works on any background). Stroke width 18 on a 256 canvas; keep the three files in step when editing.
